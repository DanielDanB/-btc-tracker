Část 1 · Framer komponenta

Instalace

  1. Ve Frameru otevři Assets → Code → New Code File.
  2. Otevři soubor EllaFramer.tsx, označ celý obsah (⌘A / Ctrl+A) a vlož ho do code file.
  3. Komponentu EllaHairSalonPage přetáhni na stránku.
  4. V pravém panelu zkontroluj úplně první pole Version – musí být v7 · Cal embed cleanup.
Pole Version je kontrolka. Když v něm svítí starší verze nebo pole chybí, Framer používá starý kód. Typicky je v code file červená chyba – Framer si pak drží poslední funkční build a panel se nezmění.

🎨 Colors – téma na jedno kliknutí

Ve skupině Colors je nahoře Theme. Přepne celý web najednou – pozadí, karty, texty, tlačítka, formulář i poletující obrazce a kurzor (ty berou akcentní barvu automaticky).

Když necháš Custom colors, máš k dispozici všechny jednotlivé barvy: pozadí, druhé pozadí, karty, akcent, světlý akcent, text, nadpisy, šedý text, rámečky, hlavičku, mobilní menu, tlačítka (pozadí, hover, text, outline), pole formuláře, patičku a barvy hlášek. Po zvolení tématu se pickery schovají, aby bylo jasné, že barvy řídí téma.

Přepínač Buttons use accent je zapnutý – tlačítka, záře i rámečky jdou automaticky s akcentní barvou. Vypni ho, když chceš tlačítkům dát vlastní barvu.

🎬 Videa

Video jde přidat všude, kde je obrázek. Video má vždy přednost před obrázkem.

KdeOvládání

Karty služebServices → Cards → Video (u každé karty zvlášť)
GalerieGallery → Items → Video (obrázky a videa lze míchat)
O násAbout → Video
Samostatná video sekceSections → Video section, pak Video section → Video
Video na pozadí stránkyBackground video → Enable + Opacity, Overlay

Chování všech videí (autoplay, smyčka, ztlumení, ovládací prvky) se nastaví jednou v Video behaviour. Autoplay si vynutí ztlumení – jinak ho prohlížeče blokují. Odkaz končící .mp4 nebo .webm funguje i v poli pro obrázek.

🏷️ Logo

Buď Logo → Logo image (PNG/SVG), nebo textové logo Text + Text (accent). Výška je v Appearance → Logo height, cíl odkazu v Logo → Link.

✨ Floating shapes – poletující obrazce

Floating shapes → Enable je hlavní vypínač. Dál si vybereš tvary (nůžky, hřeben, vlna, srdce, hvězda, jiskra, tečka, kroužek, bublina), počet, velikost, tloušťku čar, rychlost, průhlednost, otáčení a jestli mají uhýbat myši včetně jejího dosahu. Barva je ve výchozím stavu akcentní.

🖱️ Cursor – kurzor

  • System – žádný vlastní kurzor
  • Shape – 9 tvarů (původní, šipka, tečka, kroužek, nůžky, hřeben, srdce, jiskra, kapka) + barva, obrys, velikost a pozice špičky
  • Custom image – vlastní PNG/SVG kurzor

Volitelně jde nastavit jiný kurzor nad odkazy a tlačítky. Na dotykových zařízeních se vlastní kurzor nepoužije.

Vzhled kalendáře

Kalendář přebírá barvy webu (Match site colors) – pozadí, karty, texty, rámečky i akcent. Calendar theme → Auto znamená „podle webu“ (tmavý web → tmavý kalendář), ne podle systému návštěvníka. Výšku si kalendář určuje sám podle obsahu, Calendar min height je jen minimum. Vložený kalendář je ve výchozím stavu přes celou šířku – měsíční pohled potřebuje místo. Dál si nastavíš Layout (měsíc / týden / sloupec), Hide event details, text tlačítka a poznámku pod ním.

Tlačítka Book Now

V režimech s tlačítkem zajistí CTA opens booking, že i tlačítka Book Now v hlavičce a v hero sekci otevřou rezervaci.

Pojistka. Kdyby se embed nenačetl (blokovaný skript, přísné CSP, plátno Frameru), zobrazí se místo kalendáře tlačítko s odkazem na tvou stránku na Cal.com – návštěvník se objedná vždycky. Skript Cal.com se navíc načítá jen tehdy, když je rezervace zapnutá a odkaz vyplněný.

📐 Responzivita a velikost

Komponenta má šířku Fill a výšku Fit content – na šířku se roztáhne na celý rámec, na výšku se dopočítá podle obsahu. Když přidáš sekci nebo položku, rámec se zvětší sám.

Zlomy reagují na šířku samotné komponenty, ne na šířku okna prohlížeče – proto vypadá správně i v úzkém breakpoint rámci na širokém plátně.

Část 2 · HTML verze webu

Soubor web/index.html je celý web v jednom souboru – bez buildu, bez knihoven, bez CDN. Otevřeš ho dvojklikem nebo nahraješ na jakýkoli hosting (FTP, Netlify, Vercel, GitHub Pages).

Kde se co nastavuje

Úplně nahoře ve <script> je blok SITE. Je to obdoba pravého panelu ve Frameru:

const SITE = {
    theme: "noir",   // noir | midnight | emerald | gold | violet
                     // coral | mono | daylight | custom
    colors: {},      // vlastní barvy, když theme = "custom"
    style: {},       // fonty, zaoblení, mezery, výšky médií
    effects: {},     // headerBlur, heroGlow, hoverLift, pricingGlow
    shapes: {},      // { enabled: false } vypne poletující obrazce
    cursor: {},      // { mode: "Default" } vypne vlastní kurzor

    booking: { mode: "form", calLink: "" },
    form: { formspreeEndpoint: "" },
}

Všechny výchozí hodnoty jsou v objektu DEFAULTS hned pod tím – přepisuješ jen to, co chceš změnit.

Rezervace

modeCo se zobrazí
"form"kontaktní formulář
"inline"kalendář Cal.com ve stránce
"popup"tlačítko, které otevře rezervaci
"both"formulář i tlačítko
booking: {
    mode: "inline",
    calLink: "daniel-barton-c18wyl/regenerative-care",
}

Formulář

Formulář odesílá na form.formspreeEndpoint – účet zdarma na formspree.io, endpoint má tvar https://formspree.io/f/xxxxxxxx. Bez vyplněného endpointu se místo odeslání zobrazí upozornění.

Obrázky a texty

Texty se mění přímo v HTML. Obrázky se načítají ze složky assets/ vedle souboru:

web/assets/hero-salon.jpg
web/assets/service-1.jpg … service-4.jpg
web/assets/gallery-1.jpg … gallery-8.jpg
web/assets/about-salon.jpg

Dokud tam soubory nejsou, zůstanou na jejich místě tmavá pole – nic se nerozbije. Místo obrázku můžeš použít <video> se stejnými třídami.

Část 3 · Rychlé recepty

Změnit barvu celého webu

Framer: Colors → Theme a vyber téma. Nebo nech Custom colors a přenastav Accent.
HTML: uprav řádek theme: "noir".

Zapnout rezervační kalendář

Framer: Contact & booking → 📅 Booking → Cal.com calendar, pak vlož odkaz do Cal.com link. Ostatní pole nech být.
HTML: booking: { mode: "inline", calLink: "…" }.

Vypnout poletující obrazce nebo kurzor

Framer: Floating shapes → Enable vypnout, Cursor → Mode → System.
HTML: shapes: { enabled: false }, cursor: { mode: "Default" }.

Vyměnit logo

Framer: Logo → Logo image, velikost v Appearance → Logo height.
HTML: v hlavičce nahraď text v odkazu class="logo" značkou <img class="logo-image" src="assets/logo.svg" alt="Logo">.

Část 4 · Když něco nefunguje

V panelu nevidím nové nastavení

Zkontroluj pole Version úplně nahoře. Když v něm není v7 · Cal embed cleanup, Framer jede na starším kódu: otevři code file, označ všechno a vlož nový obsah. Když je v code file červená chyba, Framer si drží poslední funkční build a panel se nezmění, i když text vypadá nově.

Kalendář se nezobrazí

  • Zkoušej to v Preview nebo na publikovaném webu – plátno Frameru běží v sandboxu a externí skripty tam nemusí projít.
  • Objeví-li se po chvíli tlačítko s odkazem na Cal.com, znamená to, že se embed nenačetl – nejčastěji kvůli blokování skriptů nebo cookies třetích stran v prohlížeči.
  • Zkontroluj, že Cal.com link odpovídá skutečné události a že self-hosted pole jsou prázdná.

Web je na mobilu dole useknutý

Komponenta svoji výšku hlásí správně, ale Framer si u sekce pamatuje výšku změřenou na plátně. Vyber komponentu na telefonním breakpointu a nastav jí i rámci kolem ní Fit content, ne pevnou výšku.

Co odsud nejde ovlivnit

  • Nápis Cal.com pod kalendářem – je uvnitř jejich iframu; skrývá se jen v placeném tarifu Cal.com.
  • Odesílání formuláře – běží přes Formspree, limity má jejich účet.
